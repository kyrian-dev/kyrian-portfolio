# Kyrian | Frontend Developer Portfolio

My personal portfolio showcasing my frontend development skills, selected projects, and contact information.

I’m a Junior Frontend Developer based in Germany. I completed my professional training in Web Development at ILS Hamburg, earning the qualification Geprüfter Webentwickler.

## Features

- Responsive layout for desktop, tablet, and mobile
- Mobile navigation menu
- About and technical skills sections
- Four featured projects with live demos and source code
- Contact links for email and GitHub
- Custom SVG favicon

## Built With

- Vue 3 and the Composition API
- JavaScript
- HTML
- CSS
- Vite

## Run Locally

Install a Node.js version supported by the project's Vite version, along with npm.

From the portfolio folder, install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address shown in the terminal.

## Production Build

Create an optimised production build:

```bash
npm run build
```

Preview the build locally:

```bash
npm run preview
```
